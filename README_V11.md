# Hero Auction V11 — denetim sürümü

Bu sürüm tamamlanmış 1400 karakter paketi değildir. `npm run audit` eksik resim, açıklama ve doğrulanmamış puanları listeler. `npm run audit:strict` eksik varsa hata verir.

Çalışan oyunun mevcut teklif mekanizması değiştirilmedi. Yerel resimler ve tüm karakterlerin doğrulanmış puanları henüz eklenmedi.
